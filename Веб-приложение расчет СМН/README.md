

## Запуск  в терминале Visual Studio (можно пересобрать решение, запустить отладку,создать виртуальное окружение)
python -m flask run

## Файл Запуска
app.py

Откройте браузер: 
http://127.0.0.1:5000
http://192.168.1.48:5000

## Структура проекта

```
flask_keras_app/
├── app.py              # Основной файл Flask приложения на Python
├── model.keras         # Обученная модель (нейронная сеть)
├── requirements.txt    # Зависимости Python
├── templates/
│   └── index.html     # HTML интерфейс
└── README.md          # Инструкция
```

## Использование

1. Введите значения 8 параметров- прочностных характеристик композита и его компонентов в окошках (целочисленные или дробные значения)
2. Нажмите "Получить прогноз"
3. Получите результат предсказания модели


## Примечания

Убедитесь, что ваша модель принимает на вход массив из 8 значений показателей
Модель сохранена в формате .keras
